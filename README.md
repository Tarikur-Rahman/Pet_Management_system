#  Pet Management System

A simple **C# Console-based Pet Management System** that allows users to enter, validate, store, and display pet information. This project was developed to practice fundamental C# programming concepts such as loops, conditional statements, input validation, strings, and arrays.

---

##  Project Overview

The Pet Management System simulates a basic animal shelter record system.

Users can add pet information including:

-  Animal Species (Dog/Cat)
-  Animal ID
-  Age
-  Physical Description
-  Personality Description
-  Nickname

The application validates user input and stores the information in a 2D array before displaying the saved pet details.

---

##  Features

 User input handling  
 Dog/Cat species validation  
 Automatic animal ID generation  
 Age validation using `TryParse()`  
 Empty input handling with default value (`tbd`)  
 Store pet information using a 2D array  
 Display saved animal information
